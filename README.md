# cv-experiments

CV の基本タスク(セグメンテーション・物体検出・キーポイント検出・追跡・OCR など)を、スクラッチ実装で段階的に検証していく実験のリポジトリ。

| ディレクトリ | 中身 |
|---|---|
| [segmentation/](segmentation/) | セグメンテーションの実験(例: [segmentation/instance_segmentation/](segmentation/instance_segmentation/)) |
| [object_detection/](object_detection/) | 物体検出の実験 |
| [keypoint_detection/](keypoint_detection/) | キーポイント検出の実験 |
| [mot/](mot/) | 複数物体の追跡の実験 |
| [ocr/](ocr/) | OCR の実験 |
| [datasets/](datasets/) | データセット(評価のデータセット・合成データ)の置き場 |
| [vendor/](vendor/) | 手で取ってくる他の人のコード・モデルのファイルの置き場 |

## 全タスク共通の方針

- **モデル**: フルスクラッチで実装する。最新の公開実装は、実装の参考にするのと、比較対象としてそのまま動かすのに使う。
  モデルの構成(アーキテクチャ)の比較は一番上の観点の 1 つ。最終的に、最新の論文・公開モデルと同じかそれ以上の精度・速度を目指す
- **学習データ**: 基本は合成データ。正解ラベルは、出どころで ① 生成だけ(生成・合成の手順そのものから作り、学習済みの認識モデルは使わない)、
  ② 疑似ラベル(ラベルのない実画像に、学習済みのモデルでラベルを付ける)、③ 組み合わせ(生成した画像に認識モデルでラベルを付ける・検品する)に分け、
  混ぜずに比べる。まず ① を確かめ、② ③ はその後に比較として行う(分け方の詳細は [segmentation/instance_segmentation/README.md](segmentation/instance_segmentation/README.md#正解ラベルの作り方の分類))
- **認識モデル・判定モデル**: ② ③ で、既存のモデル(SAM 3 など)での疑似ラベルと、画像の判定モデル(decision model。選択肢ごとの較正された確率を返すモデル)での検品・誤りの原因の分類に使う
- **評価データ**: 公開されている、ラベル付きのベンチマーク
- **指標**: 精度が第一。推論の速さ(書き出し・量子化・蒸留・ブラウザやエッジでの実行)も本格的に検証し、精度と速度のトレードオフの図にする
