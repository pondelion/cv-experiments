# exp00202: ① 生成だけ で作ったデータで学習する

## 目的

① 生成だけ(正解のマスクを生成・合成の手順だけで決め、認識のモデルを一切使わない)で作ったデータで学習したモデルが、
実画像のベンチマークでどこまで届くかを測る。あわせて、背景の作り方で差が出るかを見る。

| 項目 | 内容 |
|---|---|
| 変えるもの | 学習データだけ。(a) COCO の実データ 2k 枚(`coco_train_cls8_2k`。同じ枚数の基準)/ (b) 合成 paste 2k 枚 / (c) 合成 inpaint(全クラスを否定するプロンプト)2k 枚 |
| 固定するもの | クラス(8 クラス: `lib_common.classes.CLS8`)・モデル(フェーズ C で決めたもの)・学習の長さ・val(`coco_val_dev_cls8`。最良の重みを選ぶ)・test(`coco_val_test_cls8`・`voc_val_cls8`。最終の精度) |
| わかること | 合成と実データの差、背景の作り方の差 |

最初は 20 クラスで作り始めたが、計画の見直し(instance_segmentation/README.md の「計画の見直し」)で、比較の実験の基本を
8 クラス・2,000 枚にし、フェーズ C(モデルを詰める実験)を先に行うことにした。そのため、20 クラスの合成データ voc20_v1 の場面の生成は
2,399 場面で止めてある(下の作り方・数字は 20 クラスのもの)。8 クラスの場面は、voc20_v1 の 8 クラスの物体の切り抜き・組み合わせの
プール・場所の説明文を使い、8 クラスだけで場面を計画し直して作る(フェーズ C の後)。

## 合成データ voc20_v1(`generate_data.py`)

作り方は exp00201 で決めたもの。正解のマスクは、物体を無地の背景で生成し、背景の色の規則で抜き出したものをそのまま使う。

| 段 | 内容 |
|---|---|
| 説明文 | クラスごとに 150 個、ollama の qwen3.5:9b で作る(向き・ポーズを割り当てる) |
| 1 段目 objects | 物体を 1 つずつ FLUX.2 [klein] 4B で無地の背景(クラスごとの色)に生成し、色の規則で抜き出す。20 クラス × 150 = 3,000 個 |
| filter1 | 物体のクラスを判定モデル(ollama qwen3.5:9b)で判定し、頼んだクラスの確率を記録する(捨てない) |
| combos | 場所と、そこで一緒に写ってよくあるクラスの組み合わせのプールを、ollama の gpt-oss:20b で作る(`lib_common/synthetic_data/scene_combos.py`。下) |
| place_descriptions | 場所ごとに、背景の多様な説明文を 32 個、gpt-oss:20b で作る(下) |
| 2 段目 scenes | 物体を 1〜4 個、1〜3 クラス置く。クラスごとの物体の数がそろうように、プールの組み合わせから選ぶ(下)。背景は paste(背景だけの画像を生成して貼る)と inpaint(物体以外を一から描く)の 2 通り。10,000 場面 |
| filter2 | 背景に 20 クラスの物体があるかを Intern-Decision-0.8B で判定し、確率を記録する(捨てない) |

### 場所とクラスの組み合わせ(combos)

場所と合わない組み合わせ(台所に牛など)では、背景の inpainting がうまく描けず、場面も不自然になるので、組み合わせを先に LLM で作っておき、その中から選ぶ。

1. クラスごとに、そのクラスが写っている写真としてよくある場所を、25 か所の一覧から選ばせる
2. 場所ごとに、その場所によくあるクラスの 2〜3 クラスの組み合わせを最大 15 個、クラスごとに、そのクラスとよく一緒に写るクラスと場所を最大 10 個挙げさせる
3. 挙げた組み合わせを 1 つずつ「その場所の写真として、どれだけよくあるか」を 1〜5 で答えさせ、3 以上を残す(390 個中 374 個)

LLM の選び方の経緯: qwen3.5:9b に考えさせずに即答させると、場所の選び方が甘く(猫が空に、テレビが高速道路に写るなど)、組み合わせの判定も
自然なものを落とし(居間のソファと人 0.02)不自然なものを残した(港の飛行機と椅子 0.69)。gpt-oss:20b に考えさせると(1 回数秒)まともになった。
考える部分が長いと答えが出る前に打ち切られて空になる(1 回目の作成で 8 か所の組み合わせが 0 個)ので、挙げる数を絞って聞き、空なら聞き直す。

### 背景(place_descriptions と背景の文面)

背景の文面は「a photo of {場所の説明文}. There is no person, no bicycle, …, and no tv in the image.」(paste の背景も inpaint も同じ)。
説明文は場所ごとに 32 個(時間帯・天気・季節・建物の様式や時代・地域・視点を変えさせる)。20 クラスとその言い換え(vessel・sofa・screen など)を
含む説明文は使わない(LLM に書かないよう頼んでも、港の説明文に "a single fishing vessel" などが入った)。場面ごとに、その場所の説明文を乱数で選ぶ。

背景の文面を決めた比べ方(背景だけを場所ごとに 16 枚生成して比べた。混入の割合 = Intern-Decision で「20 クラスのどれかがある」が閾値 0.388
を超えた割合、似ている度合い = 同じ場所の背景どうしの、timm の resnet50.a1_in1k の特徴のコサイン類似度の平均):

| 背景の文面 | 混入の割合(25 か所の平均) | 似ている度合い |
|---|---|---|
| 場所だけ "a photo of an empty {場所}, nobody, no animals, no vehicles"(前の paste の文面) | 30% | — |
| 場所だけ + 20 クラスを名前で否定(前の inpaint の文面。乱数の種だけ変える) | 27% | 0.825 |
| 場所の説明文 + 20 クラスを名前で否定(採用) | 18% | 0.471 |

- 前の文面は場所ごとに 1 つだけだったので、乱数の種を変えても同じ場所の背景は似ていた(0.825)。説明文を変えると 0.471 まで下がった
- 説明文にしても混入の割合が 40% 以上だった cafe(93%)・harbor(43%)・restaurant(40%)は使わない(`EXCLUDED_PLACES`)。
  boat は lake・river・beach、dining table は dining room・kitchen などが残る。場所は 22 か所
- 判定モデルは物体のない画像でも一定の割合で「ある」と答える(exp00002)ので、18% のうちどこまでが本当の混入かは、この数字だけでは分からない
- 試しの 50 場面では、閾値を超えた割合は paste 16%・inpaint 12%(前の作り方の最初の 233 場面では、どちらも 30%)

### 場面の決め方(`plan_scenes`)

場面ごとに、出すクラスの数(1〜3)と物体の数(クラスの数〜4)を等しい確率で選ぶ。1 つ目のクラスは、それまでに置いた物体がいちばん少ないクラスにする。
1 クラスなら、そのクラスがよく写る場所を選ぶ。2 クラス以上なら、そのクラスを含む組み合わせのうち、ほかのクラスの置いた物体の合計が少ない 5 個から
乱数で選ぶ(数をそろえつつ、毎回同じ組み合わせにならないように)。物体の数は各クラスに 1 個以上になるよう分け、背景の説明文はその場所の 32 個から選ぶ。
先頭から順にそろえるので、先頭の何枚を使ってもクラスごとの数はほぼそろう。

| 計画の数(画像は作らずに数えた) | 先頭 2,000 場面 | 10,000 場面 |
|---|---|---|
| クラスごとの物体の数(最小〜最大) | 300〜322 | 1,490〜1,496 |
| クラスごとの、そのクラスを含む画像の数(最小〜最大) | 156(airplane)〜273(person) | 820〜1,279 |
| 1 枚のクラスの数 1 / 2 / 3 | 658 / 705 / 637 | 3,291 / 3,602 / 3,107 |
| 1 枚の物体の数 1 / 2 / 3 / 4 | 149 / 389 / 734 / 728 | 788 / 2,086 / 3,625 / 3,501 |
| 1 枚の中の 1 クラスの物体の数 1 / 2 / 3 / 4 | 2,575 / 934 / 282 / 188 | 12,837 / 4,743 / 1,428 / 808 |

10,000 場面で、使う場所は 22 か所、(場所, 説明文)は 693 通り、(場所, クラスの組み合わせ)は 361 通り。
数えたのは置き方を決めた物体。合成のときに見える部分が 3 割未満になった物体は正解から外すので、実際の数はこれより少し減る。

- 学習には先頭の 2k 場面を使う。10k 場面は、exp00209 の枚数による精度の変化のために作って残しておく
- フィルターの確率は記録だけする。① の条件では全部の場面を使い、フィルターを通した場面だけで学習するのは ③ 組み合わせ(exp00208)で行う
- 学習データは作ってから固定して使う。エポックごとに作り直す場合との比較は、後の exp で行う
- 画像は JPEG(品質 90)、768 × 768

### 生成の時間(RTX 5090。exp00101 の学習と GPU を共有して動かした)
