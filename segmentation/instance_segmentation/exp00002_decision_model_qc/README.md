# exp00002: 画像の判定モデルでの検品の確かめ

## 目的

exp00201 の合成データは 2 段階で生成している: **1 段目** で物体を 1 つずつ無地の背景で生成し(単一の物体の生成)、
**2 段目** で、その物体を置いた画像の背景を inpainting で描く。exp00201 で、次の 2 つがわかった。

- 1 段目(単一の物体の生成)で、生成モデルがまれに**頼んだクラスではない物体(20 クラスのどれでもない「何か」)を描く**
- 2 段目(背景の inpainting)で、**背景に学習するクラスの物体を描く**(ラベルのない物体になる)
画像の判定モデル(選択肢ごとの確率を返すモデル)で、これを自動で見つけて捨てられるかを、答えのわかる問題で確かめる。
結果から、③ 組み合わせ(exp00208)の検品に使うモデルと設定(閾値)を決める。検品はラベル(マスク)には触れず、画像を捨てるかどうかだけを決める。

## まとめ

合成データを作る流れの中で、**画像を捨てるかどうかだけを決める質のフィルター**(③ 組み合わせ。ラベル(マスク)には触れない)を 2 つ置く。

```
1 段目: 単一の物体を生成 ──▶ [フィルター (1) 物体のクラス] ──▶ 色で抜く ──▶ 合成 ──▶ 2 段目: 背景を inpainting ──▶ [フィルター (2) 背景の物体] ──▶ 学習データ
                              頼んだクラスでなければ捨てる                                                      背景に 20 クラスの物体があれば捨てる
```

| フィルター | 何を防ぐか | 使うモデルと設定 | 結果(答えのわかる問題で) |
|---|---|---|---|
| (1) 物体のクラス(1 段目の後) | 1 段目の単一の物体の生成で、生成モデルが頼んだクラスではない物体(20 クラスのどれでもない「何か」や、別のクラスの物体)を描く(正解のクラスが誤る) | ollama の qwen3.5:9b に「主な物体は 20 クラス + どれでもない のどれか」を答えさせ、**頼んだクラスの確率が 0.3 以上なら残す** | 20 クラスのどれでもない物体を **96% 捨て**(別のクラスの物体は 100%)、正しい物体は 97.0% 残る。1 枚 0.2 秒 |
| (2) 背景の物体(2 段目の後) | 2 段目の背景の inpainting で、背景に 20 クラスの物体が描かれる(ラベルのない物体になり、正解の取りこぼしになる) | 置いた物体を灰色の四角で隠し、Intern-Decision-0.8B に「20 クラスのどれかが写っているか」を答えさせ、**「ある」の確率が 0.388 より大きければ捨てる** | 20 クラスの物体がある画像の **99% を捨て**、隠した合成画像の 17.3% を誤って捨てる。1 枚 0.03 秒 |

**わかったこと**

- **フィルターは「見逃さないこと」を優先して閾値を決める**: 誤って捨てても作れる枚数が減るだけだが、見逃すと正解が汚れる。
  背景のフィルターで見逃しを 1% にすると、合成画像の約 2 割を捨てることになる(作る枚数を 2 割増やせば補える)
- **判定モデルの確率の出方はモデルごとに違うので、閾値は答えのわかる問題で決める**: Intern-Decision は公式の較正で確率を低めに出す(正しいクラスでも 0.55〜0.63)ので、
  閾値は 0.3〜0.4 程度。ollama の VLM は 0.9 前後の確率を出す
- **置いた物体の隠し方で、判定が変わる**: ollama の VLM は、灰色の四角で隠した画像を、物体のない画像より「ある」と答えやすい(四角やその配置から物体があると判断している)。
  Intern-Decision は、隠した画像の方がむしろ「ある」と答えにくく、形の情報が漏れない。物体を黒く塗るとシルエットからクラスがわかってしまうので、四角で隠す
- **「どれでもない」は苦手でも、検品には使える**: Intern-Decision は 20 クラス以外の物体にも 20 クラスのどれかを選びがち(正しく「どれでもない」と答えるのは 18%)だが、
  そのクラスの確率は低いので、「頼んだクラスの確率」で決める検品には影響しない
- 2 つの判定モデルは、どちらも手元で動き、追加のダウンロードはなかった(ollama のモデル・以前に取得済みの Intern-Decision)

**残っていること**: 小さい物体だけが写っている背景での見逃しは、まだ測れていない(今回の「物体あり」の問題は、20 クラスの物体が 32² 画素以上ある画像だけ)。

## 比べるモデル

| モデル | 中身 | 確率の取り方 |
|---|---|---|
| Intern-Decision-0.8B(InternLM) | Qwen3.5-0.8B を、選択肢の記号を 1 回の計算で答えるように学習した decision model。画像を入力できる | 公式の推論のコード(`inference.py`)と同じ。答えの記号の位置の確率を、モデルごとに決められた温度(2.75)で較正する。まとめて処理する |
| qwen3.5:9b(ollama) | 画像を入力できる普通の VLM | 選択肢に記号(A, B, …)を付けて記号 1 文字で答えさせ、その 1 文字目の確率(logprobs)を記号の間で正規化する |

## 問題(どれも答えがわかっている)

| 検品 | 問題 | 正解 | 枚数 |
|---|---|---|---|
| (1) 物体のクラス(20 クラス + どれでもない) | COCO の実画像の、VOC の 20 クラスの物体の切り出し | そのクラス | 各 10 |
| | COCO の実画像の、20 クラス以外の物体(トラック・ベンチなど)の切り出し | どれでもない | 100 |
| | 生成した単一の物体(exp00201 の Q1c の llm_v3) | 頼んだクラス | 200 |
| (2) 背景に学習するクラスの物体があるか(はい / いいえ) | COCO の実画像で、20 クラスの物体がある画像 | はい | 150 |
| | COCO の実画像で、20 クラスの物体が 1 つもない画像 | いいえ | 150 |
| | 「はい」の画像の 20 クラスの物体を、物体を囲む枠を少し広げた灰色の四角で全部隠したもの | いいえ | 150 |

(2) の 3 つ目は、物体を灰色の四角で隠したときに、形の情報が漏れて「はい」と答えてしまわないかを見るためのもの
(合成画像の背景を検品するとき、置いた物体をこの方法で隠すため)。

## 測ること

- (1): 正解率。検品としての使い方(「頼んだクラスの確率」で、正しい組と、違うクラスを付けた組を分けられるか)の AUC と、閾値ごとの残す割合・誤って残す割合
- (2): 正解率、「はい」の確率での AUC、灰色の四角で隠した画像を「はい」と答えた割合
- 較正(ECE: 確率と、実際に当たる割合のずれ)、1 枚あたりの時間

## 判断の目安

| 検品 | 目安 |
|---|---|
| (1) | 頼んだクラスではない物体(20 クラスのどれでもない物体・別のクラスの物体)を、正しい物体の 1 割以下の取りこぼしで、9 割以上見つけて捨てられる |
| (2) | 20 クラスの物体が写っている背景の見逃しが 1〜2% 以下になる閾値で、灰色の四角で隠した画像(合成画像の検品と同じ形)を捨てる割合が 3 割以下(作れる枚数が大きく減らない) |

## 結果(`build_checks.py` → `eval_judges.py --judge {intern,ollama}`)

### (1) 物体のクラス

| | Intern-Decision-0.8B | ollama qwen3.5:9b |
|---|---|---|
| 正解率: COCO の 20 クラス / 20 クラス以外(正解は none)/ 生成した物体 | 91% / **18%** / 99.5% | 91% / 49% / 100% |
| 検品の AUC(頼んだクラスの確率で、正しい組と違う組を分ける) | 0.996 | 0.997 |
| 正しい物体を残す割合 / 違う物体を誤って残す割合 | 閾値 0.1: 98.0% / 2.4%、0.2: 95.0% / 1.2% | 閾値 0.3: 97.0% / 0.8%、0.5: 95.0% / 0.4% |
| 較正(ECE) | 0.34 | **0.06** |
| 1 枚あたりの時間(RTX 5090) | **49ms**(16 枚ずつまとめて) | 206ms(1 枚ずつ) |

- どちらも判断の目安を満たした
- 違う組の内訳(誤って残す割合): 20 クラス以外の物体に 20 クラスのどれかを付けた組(exp00201 で見られた「何か」にあたる)は、
  ollama(閾値 0.3)・Intern-Decision(閾値 0.2)とも **4.0%**(100 組中 4 組)。20 クラスの物体に別のクラスを付けた組は、ollama 0%・Intern-Decision 0.5%(400 組)。
  上の表の「誤って残す割合」は、この 2 つを合わせた 500 組での値
- Intern-Decision は「どれでもない」と答えるのが苦手で、20 クラス以外の物体にも 20 クラスのどれかを選びがち(18%)。ただそのクラスの確率は低いので、
  頼んだクラスの確率で残すかを決める検品には影響しない。確率は公式の較正の温度(2.75)で和らげているぶん低めに出る(ECE 0.34)ので、閾値は低くする

### (2) 背景の物体

背景の検品で大事なのは、**20 クラスの物体が写っている背景を見逃さずに捨てること**(物体のない背景を誤って捨てても、作れる枚数が減るだけで正解は汚れない)。
そこで、物体のある画像を見つける割合(見逃さない割合)をそろえて、そのときに捨てる割合を比べた。合成画像の検品では置いた物体を灰色の四角で隠して
判定させるので、**隠した画像を捨てる割合が、合成画像を誤って捨てる割合**にあたる。

| 見逃さない割合 | Intern-Decision-0.8B: 物体のない画像を捨てる / 隠した画像を捨てる | ollama qwen3.5:9b: 物体のない画像を捨てる / 隠した画像を捨てる |
|---|---|---|
| 95% | 17.3% / 12.0%(閾値 0.443) | 7.3% / 12.0%(閾値 0.935) |
| 98% | 24.0% / 14.7%(閾値 0.421) | 8.7% / 16.0%(閾値 0.912) |
| 99% | 36.7% / **17.3%**(閾値 0.388) | 18.0% / 23.3%(閾値 0.854) |
| 100%(150 枚を全部) | 80.0% / 35.3%(閾値 0.296) | 38.7% / 40.7%(閾値 0.660) |

AUC(物体あり と なし / 物体あり と 隠した)は、Intern-Decision 0.959 / 0.975、ollama 0.984 / 0.978。1 枚あたり Intern-Decision 27ms、ollama 206ms。
(この表は `results/{intern,ollama}.json` の `t2_at_recall`。判定モデルを動かさずに `eval_judges.py --judge {intern,ollama} --summary-only` で計算し直せる)

- 見逃しを 1〜2% に抑える代わりに、合成画像の 15〜20% を捨てることになる(作れる枚数が 2 割減るだけなので許容できる)
- 98% までは 2 つのモデルの差は小さく、99% 以上では Intern-Decision の方が捨てる割合が少ない
- **まだ測れていないこと**: 合成画像の背景に入り込む物体は小さいことが多いはずだが、今回の「物体あり」は 20 クラスの物体が 32² 画素以上ある画像なので、
  小さい物体だけが写った画像での見逃しは測れていない(問題を作るときに元の画像の ID を記録して、小さい物体だけの画像を足す)

### 決めたこと

| 検品 | モデル | 設定 |
|---|---|---|
| (1) 物体のクラス | ollama qwen3.5:9b | 頼んだクラスの確率が 0.3 以上なら残す |
| (2) 背景の物体 | Intern-Decision-0.8B | 置いた物体を、枠を 10% + 4 画素広げた灰色の四角で隠し、「ある」の確率が 0.388 より大きければ捨てる(見逃さない割合 99% の閾値) |

- 注意: 問題は 100〜200 枚と小さく、割合には ±3〜5 ポイントほどのぶれがある。「生成した物体」の正解は頼んだクラスとしているので、
  まれに頼んだクラスではない物体が描かれた画像は、正解の方が誤っている
- Intern-Decision は、モデルに付いている推論のコード(`inference.py`)がリンクの実体の場所(`blobs/`)からモデルを探してしまうので、
  モデルの場所を明示して渡す必要がある。速くする部品のうち `flash-linear-attention` は入れたが、`causal_conv1d` は今の torch 2.11 向けの配布がなく入れていない
