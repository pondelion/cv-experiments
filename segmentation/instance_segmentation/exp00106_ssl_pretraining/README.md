# exp00106: 自己教師ありの事前学習

## 目的

backbone をラベルのない画像・動画で自己教師ありで事前学習し、その後の少ない正解での学習(画像: `coco_train_cls8_2k`、動画:
VIPSeg)を助けるかを確かめる。画像と動画は分けて進める。どちらも backbone は ViT(timm の、全部の層が同じ解像度のもの)。

## 画像

### 条件

| 条件 | 事前学習 |
|---|---|
| 事前学習なし | ランダムな初期値から、いつもの学習だけ |
| 生成画像だけで一から | DINOv3 の自己教師ありの学習を、生成画像だけで一から |
| ImageNet の学習済みから追加 | ImageNet-1K の重み(DeiT3)から、生成画像で DINOv3 の学習を続ける |
| DINOv3 の学習済みから追加 | DINOv3 の ViT の重みから、生成画像で DINOv3 の学習を続ける |
| (参考)事前学習の重みのまま | ImageNet-1K・DINOv3 の重みを、追加の学習なしで使う |

- 事前学習に使う画像: exp002xx の生成画像(`datasets/synthetic/`)。最後の学習・評価の対象の COCO の画像は使わない(リークを防ぐ)
- 生成画像の枚数も条件にする。exp00202 の生成は途中で止めてある(`voc20_v1` は物体の切り抜き 3,000 枚がそろい、場面は予定の
  10,000 場面のうち 2,399 場面まで。8 クラスの場面はフェーズ C の後に作り直す予定)ので、使う画像と枚数は exp00202 の生成を
  再開した後に決める
- 事前学習の後: exp00105 と同じく、GTR 系の速度バランス型の構成(ViT は adapter で 3 段にする)で `coco_train_cls8_2k` を学習し、
  同じ評価をする

### 手法

DINOv3 の公式の自己教師ありの学習(facebookresearch/dinov3、`vitl_im1k_lin834.yaml` の設定)を、`lib_common/ssl/dinov3/` に自作した
もので行う(公式の機能をそろえ、重複する処理をまとめた)。

| 部品 | 中身 |
|---|---|
| データ拡張 | global crop 2 枚(224 画素)+ local crop 8 枚(96 画素)、color jitter・blur・solarize |
| 損失 | DINO(画像全体の特徴([CLS] の出力)を、crop どうしで合わせる)、iBOT(隠したパッチの特徴を当てる)、KoLeo(特徴を散らす)、Gram anchoring(パッチどうしの似かたの表を、前の時点の先生に合わせる。任意) |
| 先生 | 学生の EMA。先生の出力は Sinkhorn-Knopp で、prototype に均等に割り当てた確率にする |
| 学習率などの変化 | learning rate・weight decay・先生の EMA の係数はコサイン、先生の温度は warmup。層ごとの学習率の減衰 |

公式から入れていないもの: 複数の GPU の分散・FSDP、複数の学生を同時に蒸留する機能。

## 動画

### 条件

| 条件 | 事前学習 |
|---|---|
| 動画の事前学習なし | 画像の重み(ImageNet・DINOv3、または上の画像の事前学習の結果)のまま |
| DoRA | 動画の区間の中で、先生の ViT の attention から物体のマスクを作ってフレームの間で追い、物体ごとにマスクしたフレームを学生に入れて DINO の損失で学習する(下の「手法」) |
| V-JEPA 2.1 | 動画の一部を隠して、その特徴を当てる学習(下の「手法」) |

- 事前学習に使う動画: Kinetics-400 の train の一部(公式の配布元 CVDF の 242 個の分割から、seed 0 で 37 個。約 60GB、約 3.7 万本の見込み)。
  最後の学習・評価の対象の VIPSeg とは、YouTube の動画の ID で照らして重なる 10 本を除く(リークを防ぐ)。Something-Something V2
  (19.4GB、YouTube 由来ではない)は、入手できたら足す
- 事前学習の後: VidEoMT(exp00502)の ViT の初期値にして、VIPSeg で学習・評価する
- 進める順: VidEoMT の論文で精度を左右する「事前学習」は、画像の自己教師ありの学習(DINOv2。表 8 では DINOv3 が最良)と、
  COCO での画像のセグメンテーションの学習(段階 1)で、動画の自己教師ありの学習は使っていない。timm の DINOv3 の重みで
  論文の条件は満たせるので、exp00502 の VidEoMT の比べを先に timm の DINOv3 の重みのまま行い、動画の自己教師ありの学習
  (DoRA・V-JEPA 2.1)は、その後に「事前学習の違い」の別の比べとして行う

### 手法

| 手法 | 中身 | 論文 |
|---|---|---|
| DoRA(Discover and tRAck) | DINO(学生と、学生の EMA の先生の 2 つの ViT。先生の出力の確率に学生の出力の確率を合わせる)を動画の区間で行う。(1) 物体を見つける: 先生の ViT の最後の block の self-attention で、最初のフレームの [CLS] トークンから各パッチへの attention map(head ごとに 1 枚)で各パッチの query のベクトルを重み付けして足し、物体の特徴にする(選んだ head の数 = 物体の数)。(2) 物体を追う: 区間の各フレームで、物体の特徴と各パッチの key の内積から attention map を作り、値の大きいパッチをその物体のマスクにする。(3) 学習: 物体ごとに、マスクの外を 0 にしたフレームを学生に入れ、マスクしていないフレームを入れた先生の出力に合わせる(DINO の損失)。ViT は画像の ViT のまま使える(フレームを 1 枚ずつ入れる) | "Is ImageNet worth 1 video?"(ICLR 2024) |
| V-JEPA 2.1 | 動画の一部(2 フレーム × 16 × 16 のまとまり)を隠して、その特徴を予測する学習(JEPA)に、全部のトークンでの損失と途中の層での損失を足して、細かい特徴を強くしたもの。画像 1 枚も入れられる | Meta、2026 |

どちらも `lib_common/ssl/` に自作で実装した(`dora.py`・`vjepa.py`)。保存した ViT の重みは `lib_common/ssl/load.py` で
VidEoMT の ViT に読む(exp00502 の `--init-weights`。学習する位置の埋め込みは、読む先の大きさに補間する)。

#### DoRA の実装

| 部品 | 中身(公式の設定) |
|---|---|
| 区間 | 動画から 1 秒おきに 8 フレーム |
| データ拡張 | global crop: 区間の全フレームで同じ位置の random resized crop(300 画素、scale 0.2〜1)→ さらに同じ位置の random resized crop(224 画素、scale 0.4〜1)と左右反転。color jitter・grayscale・blur はフレームごと。local crop: 6 枚(112 画素、scale 0.05〜0.4)で、フレームごとに別の位置 |
| 物体を見つける(最初のフレーム) | ViT の self-attention は multi-head attention で、各トークンの特徴(ViT-S は 384 次元)を query・key・value にしたあと 64 次元ずつ 6 つ(head)に分け、head ごとに独立に attention の重みを計算する(head ごとに別の関係を同時に見るため。ViT-S/16 は 12 block × 6 head)。[CLS] トークンから各パッチへの attention の重みをパッチの位置に並べたもの(attention map)は、自己教師ありで学習した ViT の最後の block では物体の領域に集まり、head ごとに別の物体・部分に集まる(DINO の論文)。DoRA はこれを使い、先生の最後の block の 6 個の head から 3 個を学習の 1 回ごとにランダムに選び、1 個の head の attention map を物体 1 個の候補にする(物体 3 個)。選んだ head ごとに、その attention map の重みで各パッチの query のベクトルを足し、物体の特徴(prototype)にする。次に、先生の出力のパッチの特徴(L2 正規化)と 3 つの prototype の内積を Sinkhorn-Knopp(30 回、温度 0.05)で「各パッチをどの物体に割り当てるか」の重みにし、その重みでパッチの特徴を平均して prototype を作り直す |
| 物体を追う(区間の各フレーム) | フレームごとに、prototype と各パッチの key の内積(× 次元^−0.5)の softmax をパッチの上で取り(物体ごとの attention map)、L2 正規化した値がそのフレームの平均より大きいパッチを、その物体のマスクにする(パッチの大きさから画素に拡大) |
| 学生に入れるもの | 物体ごとに、global crop のマスクの外の画素を 0 にしたフレーム(3 物体 × 8 フレーム)と、local crop(6 枚 × 8 フレーム) |
| 損失 | DINO の損失(v1)。先生にはマスクしていない global crop を入れ、出力の [CLS] を DINO の head(65,536 次元)に通して、中心(移動平均)を引いて温度付きの softmax をとる。学生の出力(温度 0.1 の softmax)との交差エントロピーを、フレームごとに計算して平均する。マスクしたフレームの損失と local crop の損失を半分ずつ足す |

公式のコードとの違い: (1) 公式は local crop の 1 枚目を損失から常に除いている(画像の DINO の処理の残り)が、全部を使う。
(2) 公式は物体ごとの損失の和を 0 に戻していないので後の物体ほど重く足されるが、物体で平均する。(3) RoPE の ViT(DINOv3)では、
RoPE をかける前の q・k を使う。

#### V-JEPA 2.1 の実装

| 部品 | 中身(公式の ViT-B の設定) |
|---|---|
| 入力 | 動画は 4fps で 16 フレーム、256 画素(2 フレーム × 16 × 16 のまとまりをパッチにする)。画像も同時に学習する(画像 144 枚・動画 48 本の割合) |
| データ拡張 | 区間の全フレームで同じ位置の random resized crop(scale 0.3〜1)と左右反転だけ |
| 隠す場所 | 時間の全部にわたるまとまり。動画は「面積 15% × 8 個」と「70% × 2 個」、画像は「15% × 10 個」 |
| 目標 | 先生(EMA、係数 0.99925)の 4 つの層(12 層なら 3・6・9・12 層目)の出力を LayerNorm してつなげたもの |
| 損失 | 隠した場所の予測の L1 + 0.5 × 見えている場所の予測の L1(最も近い隠した場所までの距離の平方根の逆数で重み付け。0.5 は 1.5 万〜3 万 step で 0 から上げる) |
| 予測器 | 12 層、次元 384 の ViT |

公式との違い: (1) 位置の情報は、公式の 3 次元の RoPE の代わりに、timm の ViT の位置の扱い(学習する位置の埋め込みか、DINOv3 の
2 次元の RoPE)をフレームごとに使い、時間の位置の埋め込みを足す(後の VidEoMT はフレームごとに同じ ViT を使うので、ViT を
変えないため)。予測器の位置は 3 次元の固定の sin・cos。(2) 動画の 2 フレームのパッチの埋め込みは、ViT の 2 次元の埋め込みの重みを
半分ずつにした値で始める(学習済みの ViT から始めるときに、最初から同じ特徴が出るように。公式は一から)。(3) 公式は予測器の
mask token を 2 つ作るが 1 つ目しか使われないので、1 つにした。

どちらも、ViT-S(一から・DINOv3 の重みから)で数 step の学習が動くこと、包んだ ViT が timm の ViT と同じ出力を出すこと
(V-JEPA 2.1。差 1e-4 以下)、DoRA の物体のマスクがフレームの間で安定していること(物体ごとに画素の約 19%)を確かめた。
