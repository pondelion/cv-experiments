# exp00003: 追跡に使う検出の準備

## 目的

追跡の手法の比較(exp00101 以降)では、全部の手法に同じ検出を入れる。そのために、画像のインスタンスセグメンテーションのモデルの
予測(枠・確信度・クラス・マスク)を、使う全部の動画・全部のフレームで 1 回だけ作って保存する。確信度(confidence score)は予測ごとの
確からしさの値で、追跡の手法はこの値で検出を選び分ける。追跡の手法の側は保存した検出を読むだけなので、GPU を使わずに速く試せる。

## 使ったセグメンテーションのモデル

segmentation で学習したモデルを、**学習し直さずにそのまま**使う。どれも backbone は ConvNeXt-B(DINOv3 の重み)。

| セグメンテーションのモデル | 学習のデータ | 学習の名前 | 画像のマスクの AP(学習のデータの評価のセット) |
|---|---|---|---|
| GTR 系(segmentation の exp00105 の最良の構成。入力 640) | COCO の画像(8 クラス・2,000 枚、100 エポック) | `gtr_cnxtb_dinov3_bighead640s4_cls8_2k_ep100` | COCO の val の test の役 42.0 |
| GTR 系(同じ構成) | VIPSeg のフレーム(8 クラス) | `gtr_cnxtb_dinov3_bighead640s4_frames_cls8_ep100_const`(segmentation の exp00502) | VIPSeg のフレームの val 38.7 |
| Mask2Former(MinVIS の画像のモデル。入力 512) | VIPSeg のフレーム(8 クラス) | `minvis_cnxtb_dinov3_cls8_ep100_const`(segmentation の exp00502) | VIPSeg のフレームの val 33.4 |

- MOT17・DanceTrack・KITTI MOTS の画像では学習していない。トップの README の計画(各データセットの train の役のセットで学習する)
  とは違う。追跡の手法(規則の方式は学習が要らない)の比較を先に進めるため
- 使うクラス: person(MOT17・DanceTrack・KITTI MOTS の歩行者)と car(KITTI MOTS の車)。クラスは学習のデータのクラスの名前で選ぶ
  (データによってクラスの番号の並びが違うことがあるため)

## 保存したもの

3 つのモデルとも、同じ動画・同じ作り方で保存した。

| 項目 | 値 |
|---|---|
| 動画 | MOT17 の train 7 本(FRCNN の版。DPM・SDP の版は画像と正解が同じ)、DanceTrack の train 40 本 + val 25 本、KITTI MOTS の train 21 本(公式の train 12 本 + val 9 本) |
| フレーム | 合わせて 80,628 枚(評価のセットに使わない部分も含めて、動画の全部のフレーム) |
| 予測 | 1 フレームあたり、画像の評価と同じ後処理で選んだ上位の予測のうち、確信度 0.05 以上の person・car。GTR 系の確信度はクラスの確率(sigmoid)、Mask2Former はクラスの確率 × マスクの内側の確率の平均。Mask2Former には枠の head がないので、枠はマスクを囲む最小の枠 |
| マスクの解像度 | KITTI MOTS は元の画像の大きさ(マスクで評価するため)。MOT17・DanceTrack は入力の大きさ(枠だけで評価するので、マスクの拡大と保存の時間を省く) |
| 形式 | 動画ごとに `runs/{モデル}/{データセット}/{動画}.json.gz`(フレームの順に、各予測の枠(元の画像の画素の左・上・幅・高さ)・確信度・クラス・マスク(COCO の RLE))。git の対象外 |

| セグメンテーションのモデル | 学習のデータ | 1 フレームの予測の数(動画ごとの平均) | 1 フレームの時間(動画ごとの平均。読み込みと保存を含む) | 全部の時間 | 大きさ |
|---|---|---|---|---|---|
| GTR 系 | COCO の画像 | 6.0〜96.4 個 | 23〜76 ms | 約 58 分 | 203 MB |
| GTR 系 | VIPSeg のフレーム | 17.5〜99.7 個 | 25〜116 ms | 約 59 分 | 395 MB |
| Mask2Former | VIPSeg のフレーム | 4.2〜83.7 個 | 24〜98 ms | 約 51 分 | 138 MB |

時間は RTX 5090(GPU のメモリの上限 4 GB。ほかの学習と同時に動かした)で測った。作り方: `make_detections.py`(作った動画は飛ばすので、
途中で止まっても続きから作れる)。

## 確信度の分布(追跡の手法の設定に関係する)

確信度の分布はモデルによって違う。ByteTrack などの公式の設定は、検出器 YOLOX の確信度を前提にしている。MOT17-02 の person
(正解の歩行者は 1 フレームに 30 人前後)で、確信度が 0.6・0.3 を超える予測の数(1 フレームあたり):

| セグメンテーションのモデル | 学習のデータ | 確信度 > 0.6 | 確信度 > 0.3 |
|---|---|---|---|
| GTR 系 | COCO の画像 | 6.3 個 | 14.1 個 |
| GTR 系 | VIPSeg のフレーム | 4.9 個 | 12.2 個 |
| Mask2Former | VIPSeg のフレーム | 21.2 個 | 31.8 個 |

GTR 系は確信度が低めに出て、Mask2Former は高めに出る。そのため、追跡の手法の確信度の閾値は公式の値のままにせず、検出ごとに
val の役のセットで選ぶ(exp00101)。
